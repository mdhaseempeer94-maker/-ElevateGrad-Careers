# 🎯 Career Compass

Career Compass is a simple career guidance platform designed to help students discover suitable career paths after 12th based on their interests, skills, and preferences.

## 🚀 Features

* Explore different career options after 12th
* Get career suggestions based on interests
* Simple and user-friendly interface
* Interactive website built using JavaScript

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🎯 Purpose

The goal of Career Compass is to make career exploration easier for students after completing 12th and help them understand different career opportunities.

## 👨‍💻 Project

Developed as a Hackathon Project.
